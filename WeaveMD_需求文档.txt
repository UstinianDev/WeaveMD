===============================================
WeaveMD 项目需求文档 v2.0
===============================================

【项目概览】
项目名称：WeaveMD - 自然语言 Markdown 可视化笔记桌面应用
目标用户：知识工作者、开发者、内容创作者
设计对标：CareerCompass 的深色现代体系 + 几何插图风格
平台：Windows / macOS / Linux (Electron)

===============================================
【UI/UX 设计规范】
===============================================

【配色系统】
背景：#0F0F0F (深黑)
次级背景：#1A1A1A (暗灰)
边框：#2D2D2D (灰线)
主文本：#FFFFFF (白色)
副文本：#999999 (浅灰)
主强调色：#7C3AED (紫蓝)
次强调色：#6366F1 (蓝紫)

【排版】
标题 1：32px Bold
标题 2：24px Bold
正文：14px Regular
代码：JetBrains Mono 12px
字体族：-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto

【间距网格】基础 4px
xs: 4px | s: 8px | m: 16px | l: 24px | xl: 32px

【圆角】
输入框/按钮：8px
卡片/面板：12px

【交互反馈】
悬停：背景 +10% + 边框 #6366F1
焦点：边框 #7C3AED (2px)
过渡时间：150ms cubic-bezier(0.4, 0, 0.2, 1)

===============================================
【功能模块】
===============================================

【1. 加载页面】P0
- 白色背景
- 紫色 45° 渐变光线（1200ms）
- "WeaveMD" 文字淡入（800ms）
- 后台就绪时提前跳转，不等完整播放

【2. 认证系统】P0

【2.1 登录界面】
- Logo + 品牌名（顶部）
- 欢迎标题 + 副文本
- 账号输入框 (5-15位，显示历史账号下拉，最近 10 个)
- 密码输入框 + 可见性切换（眼睛图标）
- "记住密码"勾选框
- "Log in" 主按钮（紫蓝色 #7C3AED）
- "Create New Account" 链接（创建新账号，用于同一用户创建多账号）
- "Don't have an account? Register" 链接（首次用户注册）
- 底部可选：快速账号切换（已保存的近期账号快捷切换）

【2.2 注册界面】
- 标题 + 副文本
- 账号输入框 (5-15位，实时验证)
  * 规则：字母(a-z)、数字(0-9)、下划线(_)，不能以数字开头
  * 可用性检查：即时提示"此账号已被使用"或"✓ 账号可用"
  * 禁止账号列表：admin, root, system, guest 等保留字
- Password 输入框 + 可见性切换
  * 强度指示器（弱/中/强）
  * 最少 8 位，含大小写字母、数字、符号
- 验证码输入框 + 数学题
  * 格式：a [+/-/×/÷] b = ?
  * 范围：1-20 的正整数，结果为整数
  * 支持重新生成（转圈图标）
- "I have read the Terms" 复选框（可选）
- "Register" 主按钮
- "Already have an account? Sign In" 链接
- 注册成功后自动跳转登录页，填充账号并提示登录

【2.3 账号管理（在主应用设置中）】
- 当前登录账号显示
- 切换账号：快速切换到其他已注册账号，或创建新账号
- 导出账号数据：导出该账号下的所有笔记和设置为备份包
- 删除账号：删除该账号及其所有数据（确认弹框）

【3. 顶部导航栏】P0
【左侧】
- 📔 Logo/App 名 (点击自动保存)
- 当前账号标签显示 (点击下拉切换账号)
- File 菜单 ▼
  * New File
  * Open File (.md)
  * Delete File (确认弹框)
  * Save (Ctrl+S)
  * Close
- Help 菜单 ▼
  * Settings (包含账号管理选项)
  * Version (v1.1)
- History 菜单 ▼
  * 文件列表（升序，仅显示当前账号的文件）
  * Manage Files

【右侧】
- ↶ 撤销 / ↷ 重做
- ⬇️ 导出 (MD/Word/PDF)
- ⋮ 更多菜单
  * Page Width (Default/Wide/Full) P1
  * Find & Replace P1
  * Edit History P1
- _ 最小化 / □ 全屏 / ✕ 关闭

样式：背景 #1A1A1A | 文本 #FFFFFF | 菜单项悬停 #2D2D2D

【4. 编辑主区】P0
【左侧 - 目录面板】(240px 宽，可拖拽调整)
- 自动生成文档大纲（H1/H2/H3）
- 支持展开/关闭
- 点击跳转到对应位置
- 搜索文档功能（可选）

【中间 - 编辑器】
- Monaco Editor / CodeMirror 6
- 实时代码高亮（Prism.js）
- 行号显示
- 自动缩进

【浮动工具栏】(选中文本时出现)
十个按钮，从左至右：
① 结构 Θ (下拉) → Text/H1/H2/H3/Other/List/Task/Code/Quote/Highlight
② 位置 (子菜单) → 左对齐/居中/右对齐/缩进+/-
③ 粗体 [B]
④ 斜体 [I]
⑤ 下划线 [U]
⑥ 代码 [<>]
⑦ 字体色/背景色 [🎨]
⑧ 超链接 [🔗]
⑨ 复制 [📋]
⑩ 评论 [💬]

样式：背景 #1A1A1A 半透明 | 按钮边框 #2D2D2D | 悬停 #7C3AED | 位置选中文本上方 8px

【5. 设置界面】P1
【5.1 系统设置】
- 语言选择：简体中文 / 繁体中文 / English
- 外观主题（单选）：
  * Light
  * Dark (默认)
  * Light Header
  * High Contrast
  * Custom (打开自定义面板)

【5.2 账号管理】
- 当前登录账号显示
- 切换账号：列出所有已保存账号，点击快速切换
- 创建新账号：打开注册流程
- 账号信息：显示该账号下的笔记数量、创建时间、最后修改时间
- 导出账号数据：备份该账号下所有笔记和设置
- 删除账号：删除该账号及所有数据（确认弹框）

【自定义主题面板】
上方：导航栏颜色 (5 种预设圆形选择器)
下方：背景颜色 (5 种预设) + 文件上传按钮 (最大 10MB，支持 JPG/PNG/WebP)
按钮：[✓ Save] [Cancel]

【6. 窗口控制】P0
- 顶部左侧：📔 笔记图标（点击自动保存）
- 顶部右侧：最小化 _ | 全屏 □ | 关闭 ✕
- 关闭时若有未保存修改，弹出保存提示

===============================================
【优先级】
===============================================
P0 (第 1-2 周)：加载页 + 认证系统 + 编辑器基础 + 文件操作 + 窗口控制
P1 (第 3 周)：设置界面 + 导出 + 历史记录 + 搜索替换
P2 (优化阶段)：性能优化 + 国际化 + 自动更新 + 单元测试

===============================================
【关键设计决策】
===============================================
1. 账号验证规则：5-15位（字母、数字、下划线组合，不能以数字开头）
2. 多账号支持：同一用户可创建多个账号，避免单账号笔记堆积
3. 账号切换：导航栏快速显示当前账号，支持快速切换
4. 数据隔离：每个账号独立存储笔记、历史、设置，互不干扰
5. 离线使用：所有数据存储在本地 SQLite，无需网络连接
6. 分享协作：支持导出笔记为 .md 文件，好友可导入到自己的账号
