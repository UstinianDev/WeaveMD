## 图片（独立块）

整行单个图片语法即构成独立图片块，可整体对齐或缩放。语法如下：

```md
![独立图片](https://example.com/image.png)
```

### 图片对齐

用 `<div align>` 包裹图片实现居左/居中/居右：

```md
<div align="center">![居中对齐](https://example.com/image.png)</div>
```

### 图片缩放

用 `<div align="left" style="width:Npx">` 固定宽度（等比例缩放）：

```md
<div align="left" style="width:200px">![固定宽度 200px](https://example.com/image.png)</div>
```

## 行内格式

**加粗**、*斜体*、***加粗斜体***、~~删除线~~、==高亮==、<u>下划线</u>。

### 行内链接与自动链接

[WeaveMD 项目](https://example.com "示例标题")，自动链接 <https://example.com>。

### 行内图片

行内图片与链接类似，语法为 `` ![行内图](https://example.com/inline.png) ``。

### 转义

Markdown 元字符可转义：\*星号\*、\_下划线\_ 不被当作强调解析。

### 行内数学

KaTeX 公式用单个美元符包裹：$E=mc^2$ 与 $\frac{a}{b}$。
