# 需求：edit-image-align-toolbar（图片插入直选 + 图片工具栏对齐）

> 任务名：`edit-image-align-toolbar` | 日期：2026-08-11 | 状态：已确认（grill-me 三轮共识）

## 背景与问题

1. **插入中间态**：现状两段式——点浮动工具栏「图片」→ 插入 `![选中文本]()` 空占位（虚线框包住选中文本，`.inline-image-empty`）+ 弹出 ImageEditTool 弹层。用户反馈：选中 123 点图片后，123 被"一个和它差不多大的虚线长方形框住"，未展示原图。
2. **原图不显示根因（已定位）**：`toImgSrc`（`src/render/editor/kernel/inlineRenderer.ts:50`）对**已含 `%20` 转义**的 markdown src 再次 `encodeURIComponent` → 双重编码（`%20` → `%2520`）→ 主进程 `media-protocol` decode 一次后得到含字面 `%20` 的路径 → 文件不存在 → 加载失败 → `onErrorCapture` 回退 `.inline-image-fallback`（视觉同为虚线框）。带空格/中文的文件名（如截图默认命名）**必现**。
3. **无图片选中工具栏**：点击已插入图片没有任何操作能力；无对齐支持。

## 目标（用户共识）

1. **插入流程直选**：点浮动工具栏「图片」按钮 → **直接打开系统文件选择框**（`pickImage`）→ 选中文件后**直接替换选中文本为图片**（alt = 选中文本），无占位中间态；**取消 = 无操作**（不写任何内容）。URL 方式嵌入保留在「修改图片」弹层（现有 ImageEditTool 双 Tab）。
2. **修复 media:// 双重编码 bug**：带空格/中文的 Windows 路径图片真实显示。
3. **图片点击工具栏**：点击已插入图片 → 显示**图片工具栏并替换文本浮动工具栏**：`修改图片` / `内联图片` / `居左` / `居中` / `居右` / `移除图片`（按钮文案中文；「内联图片」即 marktext 的 Inline Image，中文）。
4. **对齐语义**：居左/居中/居右 → 源码变为 HTML 包裹 `<div align="left|center|right">![alt](src)</div>`（用户已确认 HTML 包裹方案）；**内联图片** = 移除包裹、恢复行内显示（默认态）。
5. **对齐前提**：图片嵌在文本行中间时，居左/居中/居右按钮**置灰不可用**；仅图片独立成块（整块内容即图片语法）时可对齐。
6. **插入完成后不自动弹出图片工具栏**，光标落在图片后；需要时点击图片操作。
7. **源码模式**：内联图显示 `![123](C:\Users\lenovo\Pictures\Screenshots\屏幕截图%202026-08-11%20003530.png)`（空格转 `%20`，与用户示例一致）；对齐图显示 `<div align="...">![123](path)</div>` 原文。
8. **修改图片**：点击 → 弹 ImageEditTool（预填 src/alt，双 Tab：本地选择/URL）→ 确认后替换 src/alt，保留对齐包裹。
9. **移除图片**：删除整段图片语法；若处于对齐包裹内，连同包裹一起删除。

## 成功标准

1. 选中文本 → 点图片 → 选文件 → 文本被图片替换（alt=选中文本），无占位框残留，光标在图后；取消 = 无操作。
2. 带空格/中文路径图片显示真实原图（渲染侧编码修复 + 主进程解码对称性验证）。
3. 点击图片 → 图片工具栏出现且文本工具栏隐藏；点击别处关闭恢复。
4. 行内图对齐按钮置灰；独立成块图片可对齐；源码一致；切源码模式往返不丢对齐。
5. 移除图片（含包裹）正确；修改图片预填并替换成功。
6. 门禁：vitest 全绿（既有 643 + 新增）、tsc 0 error、eslint 0 error、vite build 通过、e2e 既有 RED 之外全绿。

## 假设与约束

- 内容模型参考表格块先例（`types.ts:33`）：叶子原子块，text 保存原始 markdown。
- `media://` 显示层协议保持（仅修编码）；dev renderer-only 无主进程 media handler 时 404 回退占位为预期环境行为（e2e 已注明），不阻塞本任务。
- 对齐包裹严格单行格式：`<div align="left|center|right">` + 单个图片语法 + `</div>`，不允许块内含其他内容。
- 空选区插入图片：alt 为空（`![](src)`）。
- 不允许任务范围内外的顺带改动（devflow 硬约束）。
