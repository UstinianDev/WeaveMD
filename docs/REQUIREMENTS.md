# WeaveMD 需求文档

> 版本：v2.2 | 最后更新：2026-08-03

---

## 1. 产品定位

**WeaveMD** 是一款面向知识工作者、开发者和内容创作者的本地 Markdown 可视化笔记桌面应用。核心定位：**离线优先、本地存储、多账号隔离**的所见即所得 Markdown 编辑器。

## 2. 用户画像

| 角色       | 需求场景                        |
| ---------- | ------------------------------- |
| 知识工作者 | 日常笔记、知识整理、文档编写    |
| 开发者     | 技术文档、代码笔记、README 编写 |
| 内容创作者 | 长文写作、多格式导出            |

## 3. 功能需求

### 3.1 认证与账号 (P0)

| 编号    | 需求          | 优先级 | 说明                                   |
| ------- | ------------- | ------ | -------------------------------------- |
| AUTH-01 | 本地注册/登录 | P0     | 5-15 字符，仅 a-z/0-9/_，bcryptjs 加密 |
| AUTH-02 | 多账号支持    | P0     | 每个账号数据完全隔离，支持切换/删除    |
| AUTH-03 | 会话恢复      | P0     | JWT localStorage，启动时自动恢复       |
| AUTH-04 | 交互式吉祥物  | P2     | 认证页面装饰动画                       |

### 3.2 编辑器核心 (P0)

| 编号    | 需求                   | 优先级 | 说明                                                                                                                      |
| ------- | ---------------------- | ------ | ------------------------------------------------------------------------------------------------------------------------- |
| EDIT-01 | 双模式编辑             | P0     | Normal Mode（WYSIWYG）+ Source Code Mode（Monaco）                                                                        |
| EDIT-02 | 容器级 contentEditable | P0     | 跨块选择、直接编辑段落/标题                                                                                               |
| EDIT-03 | Block Tree 数据模型    | P0     | 不可变数据结构，纯函数操作                                                                                                |
| EDIT-04 | 实时格式化渲染         | P0     | Bold/Italic/Underline/Strikethrough/Highlight/InlineCode/Link/Comment，Toggle 逻辑（有→无、无→有）                        |
| EDIT-05 | MD Source 切换         | P1     | 点击工具栏 "Src" 显示当前段落 Markdown 源码，再次点击或点击其他内容恢复富文本                                             |
| EDIT-06 | 段落操作               | P0     | Enter 创建新段落、Backspace 删除空段落                                                                                    |
| EDIT-07 | 撤销/重做              | P0     | Ctrl+Z/Y，50 条上限，跨会话保留                                                                                           |
| EDIT-08 | 自动保存               | P0     | 1200ms debounce，关闭/切换前 flush                                                                                        |
| EDIT-09 | 代码块                 | P0     | 语言下拉选择 + 复制按钮；Prism 语法高亮（初次导入即高亮，切换语言后快速重高亮）；编辑通过 Source Code Mode（双击已禁用）  |
| EDIT-10 | 空块占位               | P0     | 零宽空格 + CSS ::before 显示 "Type something..."                                                                          |
| EDIT-11 | 结构转换               | P1     | 浮动工具栏下拉：正文↔H1~H4↔引用↔有序列表↔无序列表↔任务列表，类型由 resolveNextTypeFromSource 基于 detectMarkdownLine 检测 |
| EDIT-12 | 超链接交互             | P1     | 点 Link 隐藏工具栏开 Modal；edit 模式含"移除链接"按钮；Ctrl/Cmd+click 经 IPC 在系统浏览器打开；hover 蓝色 tooltip         |

### 3.3 导航与定位 (P0)

| 编号   | 需求               | 优先级 | 说明                                         |
| ------ | ------------------ | ------ | -------------------------------------------- |
| NAV-01 | 文档大纲           | P0     | H1-H3 标题树，点击导航，动态高亮当前标题     |
| NAV-02 | 大纲宽度可调       | P1     | 拖拽右侧手柄，200-500px，持久化 localStorage |
| NAV-03 | Minimap            | P1     | Canvas 文档缩影，viewport 指示器，点击导航   |
| NAV-04 | 查找替换           | P0     | Typora 风格 inline bar，支持正则，双模式可用 |
| NAV-05 | 滚动条正确反映内容 | P0     | 滑块位置和大小与实际内容对应                 |
| NAV-06 | 历史面板动态宽度   | P1     | 右边缘拖拽调整（最小 200px，无上限），持久化 localStorage |

### 3.4 文件管理 (P0)

| 编号    | 需求     | 优先级 | 说明                             |
| ------- | -------- | ------ | -------------------------------- |
| FILE-01 | 新建文件 | P0     | `untitled-{timestamp36}.md` 命名 |
| FILE-02 | 软删除   | P0     | `deleted_at` 字段，可恢复        |
| FILE-03 | 文件列表 | P0     | 按修改时间排序                   |
| FILE-04 | 历史记录 | P1     | 编辑历史追踪                     |

### 3.5 导出 (P1)

| 编号   | 需求          | 优先级 | 说明            |
| ------ | ------------- | ------ | --------------- |
| EXP-01 | Markdown 导出 | P1     | 原始 .md 文件   |
| EXP-02 | Word 导出     | P1     | .docx 格式      |
| EXP-03 | PDF 导出      | P1     | 打印式 PDF 生成 |

### 3.6 界面与交互 (P1)

| 编号  | 需求           | 优先级 | 说明                           |
| ----- | -------------- | ------ | ------------------------------ |
| UI-01 | 深色主题       | P0     | 默认暗色，5 种预设主题         |
| UI-02 | 国际化         | P1     | 中文简繁、英文三语言           |
| UI-03 | Frameless 窗口 | P1     | 自定义标题栏、拖拽区域         |
| UI-04 | 快捷键         | P0     | Ctrl+S/Ctrl+Z/Y/Ctrl+F/Ctrl+\` |
| UI-05 | 启动动画       | P2     | CSS 动画序列，可提前跳转       |

## 4. 非功能需求

| 类别 | 需求                                                 |
| ---- | ---------------------------------------------------- |
| 性能 | 大文档（10000+ 行）编辑不卡顿；格式化操作延迟 < 50ms |
| 安全 | 本地认证无网络暴露；IPC 通信仅限白名单通道           |
| 兼容 | Windows / macOS / Linux 三平台                       |
| 离线 | 全功能离线可用，无网络依赖                           |
| 数据 | SQLite 本地存储，用户数据完全本地                    |

## 5. 约束

- 不使用云服务或远程 API
- 不收集用户数据
- 不使用第三方登录
- 数据以 Markdown 纯文本为核心格式
