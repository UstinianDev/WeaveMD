# WeaveMD 需求文档

> 版本：v2.5 | 最后更新：2026-08-07

---

## 1. 产品定位

**WeaveMD** 是一款面向知识工作者、开发者和内容创作者的本地 Markdown 可视化笔记桌面应用。核心定位：**离线优先、本地存储、多账号隔离**的所见即所得 Markdown 编辑器。

## 2. 用户画像

| 角色       | 需求场景                        |
| ---------- | ------------------------------- |
| 知识工作者 | 日常笔记、知识整理、文档编写    |
| 开发者     | 技术文档、代码笔记、README 编写 |
| 内容创作者 | 长文写作、多格式导出            |

## 3. 功能需求

### 3.1 认证与账号 (P0)

| 编号    | 需求          | 优先级 | 说明                                   |
| ------- | ------------- | ------ | -------------------------------------- |
| AUTH-01 | 本地注册/登录 | P0     | 5-15 字符，仅 a-z/0-9/_，bcryptjs 加密 |
| AUTH-02 | 多账号支持    | P0     | 每个账号数据完全隔离，支持切换/删除    |
| AUTH-03 | 会话恢复      | P0     | JWT localStorage，启动时自动恢复       |
| AUTH-04 | 交互式吉祥物  | P2     | 认证页面装饰动画                       |

| 编号    | 需求                   | 优先级 | 说明                                                                                                                                                                                                                                                                  |
| ------- | ---------------------- | ------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| EDIT-01 | 双模式编辑             | P0     | Normal Mode（WYSIWYG）+ Source Code Mode（Monaco）                                                                                                                                                                                                                    |
| EDIT-02 | 容器级 contentEditable | P0     | 跨块选择、直接编辑段落/标题                                                                                                                                                                                                                                           |

| EDIT-04 | 实时格式化渲染         | P0     | Bold/Italic/Underline/Strikethrough/Highlight/InlineCode/Link/Comment，Toggle 逻辑（有→无、无→有）                                                                                                                                                                    |
| EDIT-05 | MD Source 切换         | P1     | 点击工具栏 "Src" 显示当前段落 Markdown 源码，再次点击或点击其他内容恢复富文本                                                                                                                                                                                         |
| EDIT-06 | 段落操作               | P0     | Enter 创建新段落、Backspace 删除空段落                                                                                                                                                                                                                                |
| EDIT-07 | 撤销/重做              | P0     | Ctrl+Z/Y，50 条上限，跨会话保留                                                                                                                                                                                                                                       |

| EDIT-10 | 空块占位               | P0     | 零宽空格 + CSS `::before`（绝对定位背景层 `z-index:-1`）显示 "Type something..."；仅聚焦空块显示，光标在占位符前；输入消失、删光恢复、失焦清除                                                                                                                        |

| EDIT-12 | 超链接交互             | P1     | 点 Link 隐藏工具栏开 Modal；edit 模式含"移除链接"按钮；Ctrl/Cmd+click 经 IPC 在系统浏览器打开；hover 蓝色 tooltip                                                                                                                                                     |
| EDIT-13 | 语法渲染对齐 marktext  | P1     | 标题左侧 `#`×n 光标提示（灰色、失焦隐藏）；无序/有序/任务列表、引用渲染形式与 marktext 默认主题一致（深灰 marker、圆形任务复选框、绿色引用竖线、引用非斜体）；渲染后的语法符号（圆点/数字/复选框/引用符号/标题提示）均不可鼠标选中；代码块格式不变                    |

## 4. 非功能需求

| 类别 | 需求                                                 |
| ---- | ---------------------------------------------------- |
| 性能 | 大文档（10000+ 行）编辑不卡顿；格式化操作延迟 < 50ms |
| 安全 | 本地认证无网络暴露；IPC 通信仅限白名单通道           |
| 兼容 | Windows / macOS / Linux 三平台                       |
| 离线 | 全功能离线可用，无网络依赖                           |
| 数据 | SQLite 本地存储 + 磁盘文件系统直读直写               |

## 5. 约束

- 不使用云服务或远程 API
- 不收集用户数据
- 不使用第三方登录
- 数据以 Markdown 纯文本为核心格式
