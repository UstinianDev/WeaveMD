# table-toolbar — 表格功能优化需求

## 需求清单

### R1: 浮动工具栏 — 表格插入棋盘格

在 `FloatingToolbar` 的 `OBJECT_BUTTONS` 区域新增「表格」按钮（label: `⊞` / `▦`），点击后弹出 `TablePicker` 棋盘格面板。

- **棋盘格**：6 行 × 8 列网格，鼠标悬停高亮从 (0,0) 到当前位置的矩形区域
- **底部输入框**：两个数字输入（行数 × 列数）+ 确认按钮，支持键盘增减
- **交互**：点击网格或确认按钮 → 在当前光标位置插入对应尺寸的表格 → 焦点落在第一个表头单元格
- **关闭**：点击外部 / ESC / 插入后自动关闭
- **定位**：弹窗锚定到「表格」按钮下方（类似 `InsertUrlModal` 模式）

### R2: 表格列工具栏

当用户点击表格的表头单元格（`<th>`）时，弹出 `TableColumnToolbar` 浮动工具栏。

- **触发**：点击 `<th>` 元素，工具栏显示在该列上方
- **6 个按钮**：
  - 左对齐 / 居中对齐 / 右对齐（修改 separator 行 `:---` / `:---:` / `---:`）
  - 向左插入列 / 向右插入列
  - 删除当前列
- **对齐状态**：当前列的对齐方式按钮高亮（`.active`）
- **关闭**：点击表格外部 / 切换焦点时自动关闭

### R3: tableCodec 对齐支持

扩展 `tableCodec.ts` 以支持列对齐信息：

- `TableMatrix` 新增 `alignments: ('left' | 'center' | 'right')[]` 字段
- `parseTableText` 解析 separator 行的对齐符号
- `serializeTable` 根据 alignments 生成正确的 separator 行

## 已对齐问题

1. **TableBlock 已有 +/- 按钮**：保留现有 hover 触发的行/列增删按钮，与 R2 列工具栏共存（列工具栏提供更丰富的操作）
2. **FloatingToolbar 已有 ImageToolbar 切换模式**：TablePicker 参考 `InsertUrlModal` 模式（弹层叠加），不替换整个工具栏
3. **表格创建后默认尺寸**：R1 棋盘格解决，不再使用固定 3×3

- [ ] 点击 `<th>` 弹出列工具栏（对齐+插入列+删除列）
