# 需求文档：目录区工具栏迁移

## 目标
将顶部导航栏的文件操作功能迁移到目录区工具栏，参照 Notus 原型图重新设计侧栏布局。

## 需求清单

### R1. 目录区工具栏（OutlinePanel Tab Header 重构）
工具栏从左到右：
1. **目录选项**（📑 outline tab）
2. **文件树选项**（📁 files tab）
3. **折叠按钮**（收起侧栏，已有）
4. **搜索文件/文件夹**（点击后工具栏下方展开搜索框，带×关闭）
5. **导入 Markdown**（弹出导入模态框）
6. **导出 Markdown**（从顶部导航栏迁移 ExportMenu）
7. **新建文件**（从顶部导航栏迁移）
8. **新建文件夹**（从顶部导航栏迁移）

### R2. 右键上下文菜单
在文件区右击文件或文件夹，弹出菜单：
- 重命名（inline 编辑文件名）
- 删除（根据类型判断是文件还是文件夹，执行对应删除）

### R3. 双击文件切换
在目录文件区重复点击（双击）已打开文件 → 关闭文件（替代顶部导航栏的"关闭文件"选项）

### R4. 顶部导航栏精简
- 删除 FileMenu（文件菜单）
- 删除 HistoryMenu（历史菜单）
- 删除 MoreMenu（更多/三个点菜单）
- 删除 ExportMenu（导出菜单，迁移到侧栏）
- 保留：HelpMenu、ViewMenu、Undo/Redo、Settings、WindowControls

### R5. 导入 Markdown 模态框
参照原型图：
- 标题"导入 Markdown"+ ×关闭
- "导入到"下拉框（选择目标目录：根目录 / 已打开的文件夹）
- "重名处理"下拉框（跳过已有文件 / 覆盖 / 重命名）
- 拖拽上传区 + "选择文件"/"选择目录"按钮
- "待导入文件"列表面板
- 底部"关闭"+"开始导入"按钮

### R6. 重命名功能
- 需要新增 `file.rename` IPC 通道（主进程 fs.rename）
- 渲染层 inline 编辑：双击文件名或右键→重命名进入编辑态
- Enter 确认 / Escape 取消
- 同步更新 fileTreeStore 中的 id/name/path

## 已对齐问题
- 导入功能的"选择文件"复用 `dialog.openFile`，"选择目录"复用 `dialog.openFolder`
- 重命名需要新增 IPC（`FILE_RENAME`），复用 AI Agent 已有的 rename 逻辑
- 搜索为本地文件树过滤（按文件名），不走磁盘扫描
