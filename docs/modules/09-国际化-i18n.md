# 国际化 (i18n) 功能总结

> 模块编号：09 | 优先级：P1 | 最后更新：2026-07-08

---

## 1. 功能概述

支持多语言的国际化系统，当前支持简体中文、繁体中文、英文三种语言。使用 React Context 模式实现全局翻译功能。

## 2. 架构位置

```
src/render/i18n/
├── index.tsx        # I18nProvider + useI18n hook
├── en.json          # 英文翻译（105个键）
├── zh-CN.json       # 简体中文翻译
└── zh-TW.json       # 繁体中文翻译
src/render/stores/uiStore.ts  # 语言状态管理
src/render/App.tsx            # 语言设置加载
```

## 3. 实现逻辑流程

### 3.1 Provider 初始化

```
main.tsx 渲染
  ↓
<I18nProvider>
  ↓
从 useUIStore 获取当前语言
  ↓
加载对应 JSON 字典
  ↓
提供 t() 翻译函数给所有子组件
```

### 3.2 语言切换流程

```
用户在设置中选择语言
  ↓
uiStore.setLanguage('en')
  ├── set({ language: 'en' })
  └── persistSettings() → localStorage
  ↓
I18nProvider 检测 language 变化
  ↓
重新加载 en.json 字典
  ↓
所有使用 useI18n() 的组件重新渲染
```

## 4. 实现细节

### 4.1 Provider 实现

```typescript
// src/render/i18n/index.tsx
const I18nContext = createContext<{
  t: (key: string, fallback?: string) => string;
  language: LanguageType;
  setLanguage: (lang: LanguageType) => void;
}>({
  t: (key, fallback) => fallback || key,
  language: 'zh-CN',
  setLanguage: () => {},
});

export const I18nProvider: React.FC<{ children: React.ReactNode }> = ({ children }) => {
  const language = useUIStore((s) => s.language);
  const [dictionary, setDictionary] = useState<Record<string, string>>({});

  useEffect(() => {
    // 根据 language 动态加载 JSON 字典
    import(`./${language}.json`).then((mod) => {
      setDictionary(mod.default);
    });
  }, [language]);

  const t = (key: string, fallback?: string) => {
    return dictionary[key] || fallback || key;
  };

  const setLanguage = (lang: LanguageType) => {
    useUIStore.getState().setLanguage(lang);
  };

  return (
    <I18nContext.Provider value={{ t, language, setLanguage }}>
      {children}
    </I18nContext.Provider>
  );
};

export const useI18n = () => useContext(I18nContext);
```

### 4.3 使用方式

```tsx
// 在组件中使用
import { useI18n } from '../../i18n';

const MyComponent: React.FC = () => {
  const { t } = useI18n();

  return (
    <div>
      <h1>{t('app.name')}</h1>
      <p>{t('auth.welcome')}</p>
      <button>{t('common.save')}</button>
    </div>
  );
};
```

### 4.4 翻译函数行为

| 场景                    | 返回值             |
| ----------------------- | ------------------ |
| 键存在                  | 对应语言的翻译文本 |
| 键不存在，提供 fallback | fallback 字符串    |
| 键不存在，无 fallback   | 键名本身           |

## 5. 与其他模块的交互

| 模块         | 交互方式                                                     |
| ------------ | ------------------------------------------------------------ |
| 设置         | 语言切换入口在设置界面，通过 `uiStore.setLanguage()` 触发    |
| UI Store     | 语言状态存储在 `uiStore.language`，自动持久化到 localStorage |
| 所有 UI 组件 | 通过 `useI18n()` hook 使用翻译函数                           |

## 6. 关键设计决策

1. **React Context 模式**：使用 Context 而非第三方 i18n 库，减少依赖
2. **JSON 字典**：翻译文件采用 JSON 格式，键按功能域组织，便于维护
3. **动态加载**：根据当前语言动态加载 JSON 文件，支持按需加载
4. **Fallback 机制**：翻译键找不到时回退到键名或自定义 fallback
5. **与 UI Store 绑定**：语言状态通过 Zustand 管理，自动持久化到 localStorage
