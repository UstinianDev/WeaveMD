## 一、P0 阻断缺陷修复：IPC 通道名不匹配

### 问题

`ask_question_card` 工具执行后界面卡死在"正在思考"，QuestionCard 永远不渲染。

### 根因

```
agentTaskWorker.ts:315 调用 persistAndSend(IPC_CHANNELS.AGENT_INTERACTION_QUESTION, ...)
  → persistAndSend 内部发送到 'ai:stream:agent:interaction:question'
    → preload 监听 'agent:interaction:question'（不匹配）
      → 事件丢失 → pendingInteraction 永远为 null → QuestionCard 不渲染
```

对比正常事件（chunk/tool/done/error）走 `CHANNEL_TO_EVENT_TYPE` 映射后发送到正确通道，而 `AGENT_INTERACTION_QUESTION` 不在映射表中，且 `agentTaskWorker` 直接用原始通道名调用 `persistAndSend`。

### 修复方案

1. `agentEventStore.ts` 新增 `persistOnly()` — 仅持久化到 DB（供 replayFromSeq 回放），不发送 IPC
2. `agentTaskWorker.ts` 交互事件改用 `persistOnly` + `mainWindow.webContents.send(IPC_CHANNELS.AGENT_INTERACTION_QUESTION, ...)` 直接发送
3. `replayFromSeq` 增加 `eventType === 'interaction'` 特殊处理，回放到 `agent:interaction:question` 通道
4. `AgentRunEvent.eventType` 联合类型新增 `'interaction'`

## 二、新增 deleteLocalFile 工具

### 能力

删除本地文件系统中的文件或空文件夹（永久删除，不可恢复）。与 `editLocalFile`（可编辑任意路径）形成读-写-删工具链。

### 实现

| 层 | 文件 | 说明 |
|----|------|------|
| Handler | `src/main/ai/tools/deleteLocalFile.ts` | 路径校验 + 系统路径黑名单 + unlinkSync/rmdirSync |
| Schema | 同上 | `file_path` 参数，OpenAI function schema |
| 注册 | `toolRegistry.ts` | handlerMap + CORE_TOOLS（24 工具） |
| 写工具 | `agentLoop.ts:789` | WRITE_TOOLS 集合新增 |
| 意图注入 | `agentLoop.ts:275` | toolsForIntent 基础工具集新增（所有非 chat 意图） |
| 策略 | `agentToolPolicy.ts` | allow 策略条目 |

### 安全限制

- 系统关键路径黑名单：`/windows/system`、`/program files`、`/usr`、`/bin`、`/etc` 等
- 仅支持删除文件和空文件夹（`rmdirSync`，非空返回 ENOTEMPTY 友好提示）
- 错误处理：ENOENT（不存在）、EACCES/EPERM（权限不足）

### 写控制集成

`deleteLocalFile` 加入 `WRITE_TOOLS` 后，agentLoop 的 `executeTool` 分支自动检查 `writeMode`：
- `auto` 模式：直接执行
- `manual` 模式：弹确认卡片

## 三、QuestionCard 底部滑出面板

### 变更

`QuestionCard` 从 AgentTab 消息流内联卡片重构为 AIPanelSession 底部滑出面板（bottom sheet）。

### 架构

```
AIPanelSession (flex column, position: relative)
├── 标题栏
├── AgentTab (消息流, flex-1, overflow-y-auto)
├── AIPanelComposer (底部输入框)
└── QuestionCard (absolute, bottom: 0, z-50)  ← 新位置
    ├── 半透明遮罩层 (z-40, 覆盖消息流)
    └── 滑出面板 (translateY 动画)
        ├── 拖拽指示条
        ├── 标题 + 提示
        ├── 问题列表（可滚动）
        └── 提交按钮
```

### 交互约束

- 面板显示时 composer 被遮挡（不可输入）
- 用户可向上滚动查看历史对话（消息流区域不受影响）
- 提交后面板滑回消失，composer 恢复可用
- 交互结束自动 `scrollIntoView` 到最新 AI 回复

## 四、系统通知

### 实现

`agentStore.onInteraction` 回调增加 `document.hasFocus()` 判断：

```typescript
if (!document.hasFocus()) {
  api.notification.send('WeaveMD 智能体需要您的回答', body);
}
```

- 窗口聚焦时不发送（避免打扰正在看面板的用户）
- 窗口最小化/非焦点时发送 Windows 系统通知
- 点击通知恢复窗口（`ipc-handlers.ts` 已有实现：`win.restore()` + `win.focus()`）
