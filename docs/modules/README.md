## 文档结构

每篇文档包含以下章节：

1. **功能概述** — 模块的功能描述和目标
2. **架构位置** — 涉及的源文件路径
3. **实现逻辑流程** — 核心业务流程的步骤详解（含 ASCII 流程图）
4. **实现细节** — 关键代码片段、配置、算法
5. **与其他模块的交互** — 模块间的依赖关系
6. **关键设计决策** — 技术选型和架构决策的理由

## 使用说明

- 文档按功能模块独立组织，便于查阅
- 每个文档包含完整的实现细节，可直接用于开发参考
- 使用 Context7 辅助学习了 Zustand、Electron、better-sqlite3 等关键技术栈
