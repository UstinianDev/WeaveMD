## 优化详情

### B8: expandedQueries FTS5 串行→UNION ALL 单次查询
- 文件：`src/main/ai/knowledge/kbSearch.ts`
- 变更：N 次 `db.prepare(...).all()` 合并为 1 次 UNION ALL 查询
- 预期提升：3+ 扩展查询时延迟降低 ~60%（减少 N-1 次 SQLite prepare 开销）
- 测试：14/14 kbSearch tests 全绿

### B9: vecDocRows + updatedAtMap 两次 DB 查询合并
- 文件：`src/main/ai/knowledge/kbSearch.ts`
- 变更：vecDocRows 查询增加 `d.updated_at AS updatedAt` 字段，结果补充到 updatedAtMap
- 预期提升：每次搜索减少 1 次 DB roundtrip（~2-5ms）
- 测试：14/14 kbSearch tests 全绿

### B1: listFiles 缓存 — 跳过
- 理由：`prepareAgentContext` 每次 `runAgentFlow` 只调用 1 次，不在多轮热路径上
