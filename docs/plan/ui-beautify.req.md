# UI 美化需求文档

> 任务分级：M（半天内，1-3 模块）
> 分类：功能开发 + 优化（美化）
> 约束：严格不可更改任何模块功能，仅作优化处理

## 需求清单

### R1：Composer 输入框高亮标签
**目标**：输入 `/某skill` 或 `@某文档` 时显示高亮标记标签

**验收标准**：
- [x] 输入 `/skillname` 后显示为带背景色的标签
- [x] 输入 `@docname` 后显示为带背景色的标签
- [x] 标签右侧有 `×` 按钮可删除
- [x] 鼠标悬停标签时显示下划线
- [x] 标签样式明显（背景色 + 圆角 + 边框）
- [x] 不改变现有补全逻辑功能

**技术方案**：
- 在 textarea 上方添加"已选标签"显示层
- 使用独立组件 `InputTag` 渲染标签
- 标签数据从 composer value 中解析

### R2：代码块字体美化
**目标**：统一代码块字体，增强语法高亮

**验收标准**：
- [x] 中文：阿里巴巴普惠体 B（Bold）
- [x] 英文：Consolas
- [x] 语法高亮颜色明显（关键字、字符串、注释等）
- [x] 代码块头部（语言选择器 + 复制按钮）样式优化
- [x] 适配明/暗主题

**技术方案**：
- 更新 globals.css 中 `.code-fence-content` 的 font-family
- 添加 `@font-face` 声明阿里巴巴普惠体 B
- 增强 Prism token 颜色对比度

### R3：工具栏美化
**目标**：美化浮动工具栏、表格工具栏、图片工具栏

**验收标准**：
- [x] 浮动工具栏：毛玻璃背景 + 悬停发光效果
- [x] 表格工具栏：统一风格 + 按钮悬停动效
- [x] 图片工具栏：统一风格 + 按钮悬停动效
- [x] 所有工具栏适配明/暗主题
- [x] 不改变工具栏功能和交互逻辑

**技术方案**：
- 从 Aceternity UI 提取视觉灵感（毛玻璃、发光效果）
- 使用 CSS backdrop-filter 实现毛玻璃
- 添加悬停状态 transition 动效

### R4：编辑主区整体美化
**目标**：提升编辑主区视觉质量

**验收标准**：
- [x] 块悬停效果更柔和
- [x] 选区高亮更明显
- [x] 滚动条样式优化
- [x] 字体统一（阿里巴巴普惠体 B + Consolas）

**技术方案**：
- 更新 `.editor-scroll-container` 字体配置
- 优化块悬停背景色
- 自定义滚动条样式

## 已对齐问题

1. **字体加载**：阿里巴巴普惠体 B 需要确认是否已安装或需要 @font-face 声明
2. **性能影响**：毛玻璃效果（backdrop-filter）可能影响渲染性能，需要测试
3. **兼容性**：backdrop-filter 在 Electron 中支持良好

## 不在范围内

- 不改变任何组件的功能逻辑
- 不改变补全菜单的行为
- 不改变工具栏的按钮布局
- 不添加新的依赖包
