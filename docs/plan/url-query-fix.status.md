## 问题分析

### 根本原因

用户输入 URL 并询问网站信息时，LLM 没有调用 `web_search` 工具，而是直接从 URL 提取域名并返回无意义的 JSON。

**问题链路**：
1. 用户输入 `https://www.robocom.cn/ 这是什么网站`
2. 意图分类为 `web`（正确）
3. LLM 应该调用 `web_search` 工具
4. 但 LLM 直接返回了 `{"site_name": "RoboCom.cn"}`，没有调用工具

### 问题本质

系统提示词中没有明确要求 LLM 在遇到 URL 查询时必须调用 `web_search` 工具，导致 LLM 自行决定从 URL 提取域名并返回。

## 修复方案

### 修改文件

- `src/main/ai/agent/agentPromptBuilder.ts`：在系统提示词中添加 URL 查询规则

### 修改内容

在工具规则部分添加：
```
- **URL 查询规则**：当用户提供 URL 并询问网站信息时，**必须调用 web_search 工具**搜索该网站的相关信息。不要仅从 URL 提取域名返回 JSON，必须搜索网站的实际内容、功能、背景等信息并用自然语言回答。
```
