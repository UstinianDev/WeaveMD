# Checklist

## 单界面架构

- [x] 主界面只保留一个编辑画布，没有双栏预览区域
- [x] 顶部栏不存在预览模式切换按钮或同义入口
- [x] `uiStore` 不包含预览模式状态与持久化逻辑

## 块级编辑体验

- [x] 光标进入标题块时显示完整 `#` 语法
- [x] 光标离开标题块时恢复为标题排版态
- [x] 光标进入普通段落时可直接编辑 Markdown 源文本
- [x] 用户完成段落并切换到下一块后，上一块立即进入排版态
- [x] 无序列表、有序列表和任务列表都能按块切换编辑态与排版态
- [x] 已完成任务项在排版态中带删除线和勾选反馈
- [x] 引用块在离块后呈现独立引用样式
- [x] 代码块在非激活状态下保留块级视觉样式且不与正文混排
- [ ] 表格在非激活状态下具备表头、边框和对齐表现

## 渲染与样式

- [x] H1-H6 在字号、字重和间距上有明显层级差异
- [ ] 正文行高、段后距和行内元素样式符合排版要求
- [ ] `==高亮==`、行内代码、删除线、链接、HTML 注释都具有可识别样式
- [ ] 文档左侧裸数字行号不会出现在排版结果中
- [ ] 深色主题下排版态可读性良好
- [ ] 浅色主题下排版态可读性良好

## 交互与稳定性

- [x] 回车换块、方向键跨块、鼠标点击切块行为符合预期
- [x] 浮动工具栏位置靠近选区且偏右，不遮挡主要内容
- [ ] 自动保存、撤销重做、快捷键、大纲导航、历史面板仍然正常
- [ ] 长文档下块切换无明显卡顿
- [ ] 连续写作过程中没有闪烁、错位或内容丢失

## 验证与交付

- [x] 相关单元测试已更新或补齐
- [x] TypeScript 诊断通过
- [x] ESLint/项目诊断无新增明显错误
- [ ] 已执行 `npm run dev` 审查最终效果
- [ ] 代码与规格一致并准备推送到 GitHub
